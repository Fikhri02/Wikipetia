# WikiPetia Slice 1 — Web Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the WikiPetia slice 1 web app — a course builder and a self-study player — as an installable React PWA over the API this repo already ships, finishing the slice's definition of done in a browser.

**Architecture:** Vite + React + TypeScript single-page app. All server state flows through TanStack Query; the only client state is an in-progress quiz attempt. Every API type is generated from `api/openapi.yaml`, so a renamed Go field breaks `tsc`. A block registry maps block type to component, mirroring the server's evaluator registry, so adding a block type is one component plus one parser.

**Tech Stack:** Vite 8.3, React 19.2, **TypeScript 5.9.3 (not 6.x — see constraints)**, TanStack Query 5.104, TanStack Router 1.170, Tailwind 4.3, zod 4.6, openapi-typescript 7.13, openapi-fetch 0.17, Vitest 5.0, Testing Library 16.3, Playwright 1.63, vite-plugin-pwa 1.3.

**Spec:** `docs/superpowers/specs/2026-09-26-wikipetia-slice-1-design.md`

**Companion plan:** `docs/superpowers/plans/2026-09-26-wikipetia-slice-1-api.md`, already implemented on `feature/slice-1-api` (17 tasks, 31 operations in `api/openapi.yaml`). This plan consumes that contract and adds no endpoints.

## Global Constraints

- **TypeScript is pinned to 5.9.3.** `openapi-typescript@7.13.0` declares `peer typescript@"^5.x"` and **fails to install** against TypeScript 6 with `ERESOLVE`. `npm create vite` scaffolds 6.x by default, so Task 1 downgrades it deliberately. Do not "upgrade" it.
- Pinned and verified to install and build together: vite **8.3.1**, react/react-dom **19.2.x**, @vitejs/plugin-react **6.1.1**, tailwindcss + @tailwindcss/vite **4.3.3**, @tanstack/react-query **5.104.0**, @tanstack/react-router **1.170.39**, openapi-typescript **7.13.0**, openapi-fetch **0.17.0**, zod **4.6.x**, vitest **5.0.2**, @testing-library/react **16.3.3**, @playwright/test **1.63.0**, vite-plugin-pwa **1.3.0**. Node 22.13.1, npm 11.2.0.
- **`web/src/api/types.ts` is generated and never hand-edited.** Regenerated by `make generate`; CI fails on drift.
- **The contract types everything except three fields.** `content`, `completion` and `prompt` generate as `unknown` (polymorphic `jsonb`), and arrays generate as `T[] | null` (Go slices are nilable). Every block payload is parsed with zod at the boundary; every array is normalised in the client wrapper.
- **TanStack Query is the only server-state store.** No Redux, no Zustand, no context holding fetched data. The single exception is an in-progress quiz attempt, which is component state until submit.
- **Optimistic updates in exactly two places**: drag-reorder in the builder, and mark-complete in the player. Everywhere else waits for the server.
- **No offline support.** The app is installable; service-worker content caching arrives with slice 2.
- Tailwind 4 is configured through the **Vite plugin** and `@import "tailwindcss"` — there is no `tailwind.config.js` and no PostCSS config.
- Visual target: clean and functional. A small token set, readable type, consistent spacing. No illustration, no mascots — those arrive with the engagement slice.
- Commit after every task. Branch: `feature/slice-1-web`, cut from `feature/slice-1-api`. Never commit to `main`.

### One deliberate deviation from the spec

The spec's testing section names **MSW** for API mocking, "with handlers typed from the generated OpenAPI types, so a drifted contract fails the front-end tests too". This plan mocks at the **hook** boundary (`vi.mock('../api/hooks')`) instead, and does not install MSW.

The reasoning, so the choice is reviewable rather than silent:

- Contract drift is still caught. The hooks in `api/hooks.ts` are written against the generated types, and CI regenerates them and runs `tsc`. A renamed Go field fails the typecheck, which is the guarantee the spec actually wanted.
- Hook mocking keeps component tests about the component. An MSW handler makes every test also a test of fetch wiring, query keys and serialisation — all of which the API's own tests already cover.
- It is materially faster, and these tests run on every save.

What it gives up: a component test cannot catch a *runtime* shape mismatch that the types permit — for example the API answering `null` where the type says `T[]`. That specific risk is handled by `list()` in the client wrapper and by the Playwright test, which drives the real API end to end.

If that trade looks wrong on review, adding MSW later is additive: the hooks stay, and the mock moves down a layer.

### Toolchain notes (verified by scaffolding, 2026-09-26)

- `npm create vite@latest . -- --template react-ts` now scaffolds **TypeScript ~6.0.2 and oxlint** (not ESLint). Task 1 replaces TypeScript; oxlint is kept.
- Vitest config lives **inside `vite.config.ts`** under a `test` key — no separate `vitest.config.ts` needed, and it works with Vite 8 / Vitest 5.
- `vite-plugin-pwa` 1.3.0 emits `dist/manifest.webmanifest` and `dist/sw.js` on build with no extra setup.
- TanStack Router **code-based** routing (`createRootRoute` / `createRoute` / `createRouter` plus the `declare module` Register block) typechecks cleanly. File-based routing and its generator are deliberately not used — one fewer codegen step.

- [ ] **Step 3: Write `web/src/api/errors.ts`**

```ts
import type { components } from './types'

type ErrorModel = components['schemas']['ErrorModel']

export type ApiError = {
  title: string
  detail: string
  status?: number
  /** Field name (with the `body.` prefix stripped) → message. */
  fields: Record<string, string>
}

function isErrorModel(value: unknown): value is ErrorModel {
  return typeof value === 'object' && value !== null && ('title' in value || 'status' in value)
}

/**
 * Narrows whatever openapi-fetch hands back into something a component can
 * render. The API always answers errors with problem+json, but a dropped
 * connection produces a TypeError instead, and that must not crash the UI.
 */
export function apiError(error: unknown): ApiError {
  if (isErrorModel(error)) {
    const fields: Record<string, string> = {}
    for (const detail of error.errors ?? []) {
      if (!detail?.location || !detail.message) continue
      // huma reports `body.title`; forms know the field as `title`.
      const key = detail.location.startsWith('body.')
        ? detail.location.slice('body.'.length)
        : detail.location
      fields[key] = detail.message
    }
    return {
      title: error.title ?? 'Request failed',
      detail: error.detail ?? '',
      status: error.status,
      fields,
    }
  }

  if (error instanceof Error) {
    return { title: 'Network error', detail: error.message, fields: {} }
  }

  return { title: 'Something went wrong', detail: '', fields: {} }
}

export function fieldError(err: ApiError, field: string): string | undefined {
  return err.fields[field]
}
```

```ts
import createClient from 'openapi-fetch'
import type { paths } from './types'

const DEV_USER_KEY = 'wikipetia.devUser'

/**
 * Slice 1 authenticates with a header the API's dev stub trusts completely.
 * This is a laptop-only arrangement; the spec requires a real provider before
 * slice 3, at which point only this file and the switcher change.
 */
export function devUser(): string {
  try {
    return localStorage.getItem(DEV_USER_KEY) ?? 'dev'
  } catch {
    return 'dev'
  }
}

export function setDevUser(name: string): void {
  try {
    localStorage.setItem(DEV_USER_KEY, name)
  } catch {
    // Private browsing: fall back to the default user for this session.
  }
}

export const api = createClient<paths>({
  // Same-origin through the Vite dev proxy, so there is no CORS to configure.
  baseUrl: '/api',
  headers: { 'content-type': 'application/json' },
})

api.use({
  onRequest({ request }) {
    request.headers.set('X-Dev-User', devUser())
    return request
  },
})

/**
 * Go marshals a nil slice as null, so every array in the generated types is
 * `T[] | null`. Normalising once here keeps `?? []` out of every component.
 */
export function list<T>(value: T[] | null | undefined): T[] {
  return value ?? []
}
```

```ts
import { z } from 'zod'

/**
 * These mirror api/internal/course/blockspec.go. The OpenAPI contract types
 * blocks.content, blocks.completion and questions.prompt as `unknown`, because
 * they are polymorphic jsonb on the server. Parsing them here is what restores
 * safety — and a mismatch with the Go validator shows up as a parse failure in
 * the UI rather than as a silently blank block.
 */

export const BLOCK_TYPES = ['reading', 'video_youtube', 'quiz'] as const
export type BlockType = (typeof BLOCK_TYPES)[number]

export const QUESTION_KINDS = ['mcq_single', 'true_false', 'typed'] as const
export type QuestionKind = (typeof QUESTION_KINDS)[number]

// ---- content ----

export const readingContent = z.object({ body_md: z.string().min(1) })
export const videoContent = z.object({ video_id: z.string().min(1) })
export const quizContent = z.object({})

export type ReadingContent = z.infer<typeof readingContent>
export type VideoContent = z.infer<typeof videoContent>

// ---- completion ----

export const markDoneCompletion = z.object({ kind: z.literal('mark_done') })
export const watchedCompletion = z.object({ kind: z.literal('watched_to_end') })
export const quizCompletion = z.object({
  kind: z.literal('score_threshold'),
  threshold: z.number().int().min(0).max(100),
})

export type QuizCompletion = z.infer<typeof quizCompletion>

// ---- question prompts ----

export const mcqPrompt = z.object({
  text: z.string().min(1),
  options: z.array(z.string()).min(2),
})
export const textPrompt = z.object({ text: z.string().min(1) })

export type McqPrompt = z.infer<typeof mcqPrompt>
export type TextPrompt = z.infer<typeof textPrompt>

// ---- parse helpers ----

export type ParseResult<T> = { ok: true; data: T } | { ok: false; message: string }

function run<T>(schema: z.ZodType<T>, value: unknown): ParseResult<T> {
  const parsed = schema.safeParse(value)
  if (parsed.success) return { ok: true, data: parsed.data }
  const first = parsed.error.issues[0]
  const path = first?.path.join('.')
  return { ok: false, message: path ? `${path}: ${first.message}` : (first?.message ?? 'invalid') }
}

const contentSchemas = {
  reading: readingContent,
  video_youtube: videoContent,
  quiz: quizContent,
} as const

export function parseBlockContent(
  type: string,
  value: unknown,
): ParseResult<ReadingContent | VideoContent | Record<string, never>> {
  const schema = contentSchemas[type as BlockType]
  if (!schema) return { ok: false, message: `unknown block type "${type}"` }
  return run(schema, value)
}

const promptSchemas = {
  mcq_single: mcqPrompt,
  true_false: textPrompt,
  typed: textPrompt,
} as const

export function parseQuestionPrompt(
  kind: string,
  value: unknown,
): ParseResult<McqPrompt | TextPrompt> {
  const schema = promptSchemas[kind as QuestionKind]
  if (!schema) return { ok: false, message: `unknown question kind "${kind}"` }
  return run(schema, value)
}

export function parseQuizCompletion(value: unknown): QuizCompletion {
  const parsed = quizCompletion.safeParse(value)
  // A quiz block always has a completion rule; the server defaults it to 70.
  return parsed.success ? parsed.data : { kind: 'score_threshold', threshold: 70 }
}
```

```ts
import { useMutation, useQuery, useQueryClient } from '@tanstack/react-query'
import { api, list } from './client'
import { apiError, type ApiError } from './errors'

/** Query keys in one place, so an invalidation can never miss by a typo. */
export const qk = {
  enrolments: ['enrolments'] as const,
  player: (id: string) => ['enrolments', id] as const,
  courses: ['courses'] as const,
  course: (id: string) => ['courses', id] as const,
  outline: (id: string) => ['courses', id, 'outline'] as const,
  questions: (blockId: string) => ['blocks', blockId, 'questions'] as const,
}

/**
 * Throws a narrowed ApiError so every component handles one shape.
 *
 * The `response.ok` check is not belt-and-braces. A dead API behind the Vite
 * dev proxy answers 500 with a plain-text body, so openapi-fetch leaves `error`
 * undefined — and returning `undefined` then made a down server render as an
 * EMPTY library, telling the learner they had no courses. Exported for tests.
 */
export function unwrap<T>(result: { data?: T; error?: unknown; response: Response }): T {
  if (result.error !== undefined) throw apiError(result.error)
  if (!result.response.ok) {
    throw apiError(
      new Error(`server returned ${result.response.status} ${result.response.statusText}`.trim()),
    )
  }
  if (result.data === undefined) {
    throw apiError(new Error('the server returned an empty response body'))
  }
  return result.data
}

/**
 * For the 204 No Content endpoints (archives and moves). These cannot use
 * `unwrap`, which requires a body — but they must not use a bare
 * `error !== undefined` check either: openapi-fetch leaves `error` undefined for
 * ANY response with no body, non-ok included, so a 502 from a gateway was
 * indistinguishable from a successful 204. An archive that failed reported
 * success, and a failed move never rolled its optimistic update back.
 */
export function expectNoContent(result: { error?: unknown; response: Response }): void {
  if (result.error !== undefined) throw apiError(result.error)
  if (!result.response.ok) {
    throw apiError(
      new Error(`server returned ${result.response.status} ${result.response.statusText}`.trim()),
    )
  }
}

export type { ApiError }

export function useEnrolments() {
  return useQuery({
    queryKey: qk.enrolments,
    queryFn: async () => {
      const res = await api.GET('/enrolments', {})
      return list(unwrap(res).enrolments)
    },
  })
}

export function useMyCourses() {
  return useQuery({
    queryKey: qk.courses,
    queryFn: async () => {
      const res = await api.GET('/courses', {})
      return list(unwrap(res).courses)
    },
  })
}

export function useOutline(courseId: string) {
  return useQuery({
    queryKey: qk.outline(courseId),
    queryFn: async () => {
      const res = await api.GET('/courses/{id}/outline', { params: { path: { id: courseId } } })
      return unwrap(res)
    },
  })
}

export function usePlayer(enrolmentId: string) {
  return useQuery({
    queryKey: qk.player(enrolmentId),
    queryFn: async () => {
      const res = await api.GET('/enrolments/{id}', { params: { path: { id: enrolmentId } } })
      return unwrap(res)
    },
  })
}

export function useEnrol() {
  const qc = useQueryClient()
  return useMutation({
    mutationFn: async (courseId: string) => {
      const res = await api.POST('/enrolments', {
        body: { course_id: courseId, mode: 'self_study' },
      })
      return unwrap(res)
    },
    onSuccess: () => qc.invalidateQueries({ queryKey: qk.enrolments }),
  })
}
```

- [ ] **Step 3: Write `web/src/features/builder/reorder.ts`**

```ts
/**
 * Computes the reordered list AND the anchor the API needs, from one place, so
 * the optimistic update and the request can never disagree.
 *
 * The API takes `before` or `after` naming a SIBLING, never a position, so the
 * anchor is read off the list after the move.
 */
export function moveWithin<T extends { id: string }>(
  items: T[],
  id: string,
  direction: -1 | 1,
): { next: T[]; before?: string; after?: string } {
  const from = items.findIndex((i) => i.id === id)
  if (from < 0) return { next: items }

  const to = from + direction
  if (to < 0 || to >= items.length) return { next: items }

  const next = items.slice()
  const [moved] = next.splice(from, 1)
  next.splice(to, 0, moved)

  const position = next.findIndex((i) => i.id === id)
  if (direction === -1) {
    // Moving up: sit before whatever now follows.
    const successor = next[position + 1]
    return { next, before: successor?.id }
  }
  // Moving down: sit after whatever now precedes.
  const predecessor = next[position - 1]
  return { next, after: predecessor?.id }
}
```

```ts
/**
 * Optimistic: the list reorders under the cursor, and rolls back if the server
 * disagrees. One of only two optimistic mutations in the app.
 */
export function useMoveModule(courseId: string) {
  const qc = useQueryClient()
  return useMutation({
    mutationFn: async (vars: {
      id: string
      before?: string
      after?: string
      /** The reordered outline to show while the request is in flight. */
      optimistic?: unknown
    }) => {
      const res = await api.POST('/modules/{id}/move', {
        params: { path: { id: vars.id } },
        body: { before: vars.before, after: vars.after },
      })
      expectNoContent(res)
    },
    onMutate: async (vars) => {
      await qc.cancelQueries({ queryKey: qk.outline(courseId) })
      const previous = qc.getQueryData(qk.outline(courseId))
      if (vars.optimistic) {
        qc.setQueryData(qk.outline(courseId), vars.optimistic)
      }
      return { previous }
    },
    onError: (_err, _vars, context) => {
      // Put the server's truth back; the UI briefly showed a lie.
      if (context?.previous) qc.setQueryData(qk.outline(courseId), context.previous)
    },
    onSettled: () => qc.invalidateQueries({ queryKey: qk.outline(courseId) }),
  })
}
```

```tsx
import { useState } from 'react'
import { useQueryClient } from '@tanstack/react-query'
import {
  qk,
  useArchiveModule,
  useCreateModule,
  useMoveModule,
  useRenameModule,
} from '../../api/hooks'
import { moveWithin } from './reorder'
import { BlockList } from './BlockList'
import { Button } from '../../components/Button'
import { Card } from '../../components/Card'
import { EmptyState } from '../../components/EmptyState'
import { ErrorBanner } from '../../components/ErrorBanner'
import { Field } from '../../components/Field'
import { asApiError } from '../../api/errors'

type ModuleShape = { id: string; title: string; sort_key: string; blocks?: unknown }
type TopicShape = { id: string; title: string }

export function ModuleList({
  courseId,
  modules,
  topics,
}: {
  courseId: string
  modules: ModuleShape[]
  topics: TopicShape[]
}) {
  const qc = useQueryClient()
  const create = useCreateModule(courseId)
  const rename = useRenameModule(courseId)
  const archive = useArchiveModule(courseId)
  const move = useMoveModule(courseId)
  const [title, setTitle] = useState('')

  function reorder(id: string, direction: -1 | 1) {
    const { next, before, after } = moveWithin(modules, id, direction)
    if (!before && !after) return // already at the edge

    // Optimistic: rewrite the cached outline with the new module order.
    const current = qc.getQueryData(qk.outline(courseId)) as { modules?: ModuleShape[] } | undefined
    const optimistic = current ? { ...current, modules: next } : undefined

    move.mutate({ id, before, after, optimistic })
  }

  // Reorder and archive are easy to fail silently: the optimistic update rolls
  // back and the list simply snaps to its old order. Surface every one.
  const failure = asApiError(create.error ?? rename.error ?? archive.error ?? move.error)

  return (
    <section className="space-y-4">
      <ErrorBanner error={failure} />

      <form
        className="flex items-end gap-3"
        onSubmit={(e) => {
          e.preventDefault()
          const value = title.trim()
          if (!value) return
          // Clear on SUBMIT, not on success. Clearing in onSuccess wipes text
          // the user has already typed for the next item, and then submits an
          // empty title the server rejects. Restore it if the create fails.
          setTitle('')
          create.mutate(value, { onError: () => setTitle(value) })
        }}
      >
        <div className="flex-1">
          <Field
            label="New module"
            value={title}
            onChange={(e) => setTitle(e.target.value)}
            placeholder="Module 1 — Matter"
          />
        </div>
        <Button type="submit" disabled={create.isPending}>
          Add module
        </Button>
      </form>

      {modules.length === 0 && (
        <EmptyState title="No modules yet" hint="A course is a list of modules, each a list of blocks." />
      )}

      <ol className="space-y-4">
        {modules.map((m, index) => (
          <li key={m.id}>
            <Card className="space-y-3">
              <div className="flex items-center gap-2">
                <input
                  defaultValue={m.title}
                  aria-label={`Module title: ${m.title}`}
                  onBlur={(e) => {
                    if (e.target.value !== m.title) rename.mutate({ id: m.id, title: e.target.value })
                  }}
                  className="flex-1 rounded border border-transparent px-1 py-0.5 font-medium hover:border-line focus:border-line focus:outline-none"
                />
                <Button
                  variant="ghost"
                  aria-label={`Move ${m.title} up`}
                  disabled={index === 0}
                  onClick={() => reorder(m.id, -1)}
                >
                  ↑
                </Button>
                <Button
                  variant="ghost"
                  aria-label={`Move ${m.title} down`}
                  disabled={index === modules.length - 1}
                  onClick={() => reorder(m.id, 1)}
                >
                  ↓
                </Button>
                <Button
                  variant="ghost"
                  aria-label={`Archive ${m.title}`}
                  onClick={() => archive.mutate(m.id)}
                >
                  Archive
                </Button>
              </div>

              <BlockList courseId={courseId} moduleId={m.id} blocks={(m.blocks as never) ?? []} topics={topics} />
            </Card>
          </li>
        ))}
      </ol>
    </section>
  )
}
```

```tsx
  const archive = useArchiveBlock(courseId)
  const move = useMoveBlock(courseId)

  const [type, setType] = useState<BlockType>('reading')
  const [openId, setOpenId] = useState<string | null>(null)

  const typeId = useId()

    const { before, after } = moveWithin(blocks, id, direction)

          if (!value) return
          // Clear on submit, restore on failure — see TopicPanel.

            { onError: () => setTitle(value) },

            value={title}
            onChange={(e) => setTitle(e.target.value)}
```

```ts
  return useMutation({
    mutationFn: async (vars: { blockId: string; topicIds: string[] }) => {
      const res = await api.PUT('/blocks/{id}/topics', {
        params: { path: { id: vars.blockId } },
        body: { topic_ids: vars.topicIds },

      return unwrap(res)

  return useQuery({
    queryKey: qk.questions(blockId),
    enabled,
    queryFn: async () => {
      const res = await api.GET('/blocks/{id}/questions', { params: { path: { id: blockId } } })
      return list(unwrap(res).questions)
    },
  })
}

export function useCreateQuestion(blockId: string, courseId: string) {
  const qc = useQueryClient()
  return useMutation({
    mutationFn: async (vars: {
      kind: 'mcq_single' | 'true_false' | 'typed'
      topic_id?: string
      prompt: unknown
      answer: unknown
    }) => {
      const res = await api.POST('/blocks/{id}/questions', {
        params: { path: { id: blockId } },
        body: vars,
      })
      return unwrap(res)
    },
    onSuccess: () => {
      qc.invalidateQueries({ queryKey: qk.questions(blockId) })
      // question_count lives on the outline.
      qc.invalidateQueries({ queryKey: qk.outline(courseId) })
    },
  })
}

  const qc = useQueryClient()
  return useMutation({
    mutationFn: async (id: string) => {
      const res = await api.POST('/questions/{id}/archive', { params: { path: { id } } })
      expectNoContent(res)
    },
    onSuccess: () => {

      qc.invalidateQueries({ queryKey: qk.outline(courseId) })
```

```tsx
    const next = new Set(tagged)

          pending={update.isPending}
```

```tsx
export function PlayerPage() {
  const { enrolmentId } = useParams({ from: '/learn/$enrolmentId' })
  const player = usePlayer(enrolmentId)
  const [selectedId, setSelectedId] = useState<string | null>(null)

  const blocks = useMemo(
    () => (player.data?.modules ?? []).flatMap((m) => m.blocks ?? []),
    [player.data],
  )

  const selected =
    blocks.find((b) => b.id === selectedId) ??
    blocks.find((b) => b.status !== 'completed') ??

  // re-evaluated on every render, so completing a block yanks the learner to
  // the next one and they never see the confirmation they just earned.
  useEffect(() => {
    if (selectedId === null && selected) setSelectedId(selected.id)
  }, [selectedId, selected])

  if (player.isLoading) return <Spinner />
  if (player.error) return <ErrorBanner error={player.error as ApiError} />
  if (!player.data) return null

  return (
    <div className="space-y-6">
      <header>
        <h1 className="text-xl font-semibold tracking-tight">{player.data.course_title}</h1>
        <p className="text-sm text-muted">
```

```ts
export function useCompleteBlock(enrolmentId: string) {
  const qc = useQueryClient()
  return useMutation({
    mutationFn: async (vars: {
      blockId: string
      marked_done?: boolean
      watched_to_end?: boolean
    }) => {
      const res = await api.POST('/enrolments/{enrolment_id}/blocks/{block_id}/complete', {
        params: { path: { enrolment_id: enrolmentId, block_id: vars.blockId } },
        body: { marked_done: vars.marked_done, watched_to_end: vars.watched_to_end },
      })
      return unwrap(res)
    },
    // Optimistic: marking a reading done should feel instantaneous.
    onMutate: async (vars) => {
      await qc.cancelQueries({ queryKey: qk.player(enrolmentId) })
      const previous = qc.getQueryData(qk.player(enrolmentId))

      qc.setQueryData(qk.player(enrolmentId), (old: unknown) => {
        if (!old || typeof old !== 'object') return old
        const view = old as {
          blocks_completed: number
          modules?: { blocks?: { id: string; status: string }[] | null }[] | null
        }
        let newlyCompleted = 0
        const modules = (view.modules ?? []).map((m) => ({
          ...m,
          blocks: (m.blocks ?? []).map((b) => {
            if (b.id !== vars.blockId || b.status === 'completed') return b
            newlyCompleted += 1
            return { ...b, status: 'completed' }
          }),
        }))
        return { ...view, modules, blocks_completed: view.blocks_completed + newlyCompleted }
      })

      return { previous }
    },
    onError: (_err, _vars, context) => {
      if (context?.previous) qc.setQueryData(qk.player(enrolmentId), context.previous)
    },
    // The server owns mastery and the real completion time; always reconcile.
    onSettled: () => qc.invalidateQueries({ queryKey: qk.player(enrolmentId) }),
  })
}
```

```ts
import { useEffect, useRef, useState } from 'react'

/**
 * @types/youtube declares the YT namespace but NOT this global callback, which
 * is how the IFrame API announces readiness. Declaring it here keeps the loader
 * cast-free.
 */
declare global {
  interface Window {
    onYouTubeIframeAPIReady?: () => void
  }
}

let apiPromise: Promise<typeof YT> | null = null

/** Test-only hook to clear module state between cases. */
export function __resetYouTubeApiForTests() {
  apiPromise = null
}

/**
 * Loads the IFrame Player API once per page, however many video blocks ask.
 * The API announces readiness through a single global callback, so every
 * caller waits on one shared promise.
 */
export function loadYouTubeApi(): Promise<typeof YT> {
  if (window.YT?.Player) return Promise.resolve(window.YT)
  if (apiPromise) return apiPromise

  apiPromise = new Promise<typeof YT>((resolve, reject) => {
    const previous = window.onYouTubeIframeAPIReady
    window.onYouTubeIframeAPIReady = () => {
      previous?.()
      resolve(window.YT)
    }

    const script = document.createElement('script')
    script.src = 'https://www.youtube.com/iframe_api'
    script.async = true
    // Without this the promise can only ever resolve, so an offline learner —
    // or one behind an extension or DNS block — waits forever on a black box
    // with no error and no way to complete the block.
    script.onerror = () => {
      // Clear the cached promise so a remount can retry rather than inheriting
      // this rejection for the life of the page.
      apiPromise = null
      reject(new Error('the YouTube player could not be loaded'))
    }
    document.head.appendChild(script)
  })

  return apiPromise
}

/**
 * Mounts a YouTube player and calls onEnded when the video genuinely finishes.
 *
 * This is why the video block is verifiable at all: the player reports its own
 * ENDED state, so completion is observed rather than asserted by the learner.
 */
export function useYouTubePlayer({
  videoId,
  onEnded,
}: {
  videoId: string
  onEnded: () => void
}) {
  const containerRef = useRef<HTMLDivElement | null>(null)
  const [ready, setReady] = useState(false)
  const [failed, setFailed] = useState(false)

  // Kept in a ref so re-renders never tear down and rebuild the player.
  const onEndedRef = useRef(onEnded)
  onEndedRef.current = onEnded

  useEffect(() => {
    let cancelled = false
    let player: YT.Player | undefined

    loadYouTubeApi()
      .then((api) => {
        if (cancelled || !containerRef.current) return
        player = new api.Player(containerRef.current, {
          videoId,
          playerVars: { rel: 0, modestbranding: 1 },
          events: {
            onReady: () => !cancelled && setReady(true),
            onStateChange: (event) => {
              if (event.data === api.PlayerState.ENDED) onEndedRef.current()
            },
            onError: () => !cancelled && setFailed(true),
          },
        })
      })
      .catch(() => !cancelled && setFailed(true))

    return () => {
      cancelled = true
      player?.destroy()
    }
  }, [videoId])

  return { containerRef, ready, failed }
}
```

```tsx
import { videoContent } from './schemas'
import { useYouTubePlayer } from './useYouTubePlayer'
import type { PlayerBlockProps } from './players'

export function VideoBlock({ block, onComplete }: PlayerBlockProps) {
  const parsed = videoContent.safeParse(block.content)
  const videoId = parsed.success ? parsed.data.video_id : ''
  const done = block.status === 'completed'

  const { containerRef, failed } = useYouTubePlayer({
    videoId,
    // Fires on the player's own ENDED state. Posting again after completion is
    // harmless: the API is idempotent and emits no second event.
    onEnded: () => onComplete({ watched_to_end: true }),
  })

  if (!parsed.success) {
    return <p className="text-sm text-red-700">This video could not be displayed.</p>
  }

  return (
    <article className="space-y-4">
      <h2 className="text-lg font-semibold">{block.title}</h2>

      <div className="aspect-video w-full overflow-hidden rounded-lg bg-slate-900">
        <div ref={containerRef} className="h-full w-full" />
      </div>

      {failed && (
        <p className="text-sm text-red-700">
          This video failed to load. It may have been removed or made private by its owner.
        </p>
      )}

      <p className="text-sm text-muted">
        {done ? 'Completed' : 'This completes itself when the video reaches the end.'}
      </p>
    </article>
  )
}
```

```ts
export type SubmittedAnswer = {
  question_id: string
  choice_index?: number
  boolean?: boolean
  text?: string
}

export function useSubmitQuiz(enrolmentId: string) {
  const qc = useQueryClient()
  return useMutation({
    mutationFn: async (vars: { blockId: string; answers: SubmittedAnswer[] }) => {
      const res = await api.POST('/enrolments/{enrolment_id}/blocks/{block_id}/submit', {
        params: { path: { enrolment_id: enrolmentId, block_id: vars.blockId } },
        body: { answers: vars.answers },
      })
      return unwrap(res)
    },
    // Not optimistic: only the server knows the score, and guessing it would be
    // the one lie a learner would actually notice.
    onSuccess: () => qc.invalidateQueries({ queryKey: qk.player(enrolmentId) }),
  })
}
```

```tsx
import { useState } from 'react'
import { useSubmitQuiz, type SubmittedAnswer } from '../api/hooks'
import { parseQuestionPrompt, parseQuizCompletion } from './schemas'
import { Button } from '../components/Button'
import { ErrorBanner } from '../components/ErrorBanner'
import type { PlayerBlockProps } from './players'
import type { ApiError } from '../api/errors'

type Draft = Record<string, SubmittedAnswer>

export function QuizBlock({ enrolmentId, block }: PlayerBlockProps) {
  const submit = useSubmitQuiz(enrolmentId)
  // Local until submit: the server never hears about a half-finished attempt.
  const [draft, setDraft] = useState<Draft>({})

  const questions = block.questions ?? []
  const threshold = parseQuizCompletion(block.completion).threshold
  const result = submit.data
  const resultById = new Map((result?.results ?? []).map((r) => [r.question_id, r.correct]))

  function setAnswer(questionId: string, answer: Omit<SubmittedAnswer, 'question_id'>) {
    setDraft((d) => ({ ...d, [questionId]: { question_id: questionId, ...answer } }))
  }

  return (
    <article className="space-y-5">
      <h2 className="text-lg font-semibold">{block.title}</h2>

      {questions.length === 0 && (
        <p className="text-sm text-muted">This quiz has no questions yet.</p>
      )}

      <ol className="space-y-5">
        {questions.map((q, index) => {
          const parsed = parseQuestionPrompt(q.kind, q.prompt)
          if (!parsed.ok) {
            return (
              <li key={q.id} className="text-sm text-red-700">
                Question {index + 1} could not be displayed.
              </li>
            )
          }

          const outcome = resultById.get(q.id)

          return (
            <li key={q.id} className="space-y-2">
              <p className="text-sm font-medium">{parsed.data.text}</p>

              {q.kind === 'mcq_single' && 'options' in parsed.data && (
                <div className="space-y-1">
                  {parsed.data.options.map((option, optionIndex) => (
                    <label key={option} className="flex items-center gap-2 text-sm">
                      <input
                        type="radio"
                        name={q.id}
                        aria-label={option}
                        checked={draft[q.id]?.choice_index === optionIndex}
                        onChange={() => setAnswer(q.id, { choice_index: optionIndex })}
                      />
                      {option}
                    </label>
                  ))}
                </div>
              )}

              {q.kind === 'true_false' && (
                <div className="flex gap-4">
                  {[true, false].map((value) => (
                    <label key={String(value)} className="flex items-center gap-2 text-sm">
                      <input
                        type="radio"
                        name={q.id}
                        aria-label={value ? 'True' : 'False'}
                        checked={draft[q.id]?.boolean === value}
                        onChange={() => setAnswer(q.id, { boolean: value })}
                      />
                      {value ? 'True' : 'False'}
                    </label>
                  ))}
                </div>
              )}

              {q.kind === 'typed' && (
                <input
                  aria-label={parsed.data.text}
                  value={draft[q.id]?.text ?? ''}
                  onChange={(e) => setAnswer(q.id, { text: e.target.value })}
                  className="w-full rounded-md border border-line px-2.5 py-1.5 text-sm"
                />
              )}

              {outcome !== undefined && (
                <p className={`text-xs ${outcome ? 'text-emerald-700' : 'text-red-700'}`}>
                  {outcome ? 'Correct' : 'Incorrect'}
                </p>
              )}
            </li>
          )
        })}
      </ol>

      {questions.length > 0 && (
        <Button
          onClick={() =>
            submit.mutate({
              blockId: block.id,
              // Only what was actually answered; the server counts the rest wrong.
              answers: questions.map((q) => draft[q.id]).filter(Boolean),
            })
          }
          disabled={submit.isPending}
        >
          Submit answers
        </Button>
      )}

      {result && (
        <div className="rounded-md border border-line p-3 text-sm">
          <p className="font-medium">You scored {result.score}%</p>
          <p className="mt-0.5 text-muted">
            {result.score >= threshold
              ? 'That clears the bar for this block.'
              : `That is below the ${threshold}% needed to complete this block — try again.`}
          </p>
          {(result.mastery ?? []).length > 0 && (
            <p className="mt-2 text-xs text-muted">
              Mastery updated: {(result.mastery ?? []).map((m) => m.level).join(', ')}
            </p>
          )}
        </div>
      )}

      <ErrorBanner error={(submit.error as ApiError | null) ?? null} />
    </article>
  )
}
```
